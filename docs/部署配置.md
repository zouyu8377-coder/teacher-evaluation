## 六、一键部署命令

### Windows PowerShell

```powershell
# 1. 构建后端
cd C:\TeacherEvaluation\backend
mvn clean package -DskipTests

# 2. 构建前端
cd C:\TeacherEvaluation\frontend
npm run build

# 3. 构建并推送后端镜像
cd C:\TeacherEvaluation\backend
docker build -t teacher-eval-cn-beijing.cr.volces.com/teacher-eval/teacher-eval-backend:latest .
docker push teacher-eval-cn-beijing.cr.volces.com/teacher-eval/teacher-eval-backend:latest

# 4. 构建并推送前端镜像
cd C:\TeacherEvaluation\frontend
docker build -t teacher-eval-cn-beijing.cr.volces.com/teacher-eval/teacher-eval-frontend:latest .
docker push teacher-eval-cn-beijing.cr.volces.com/teacher-eval/teacher-eval-frontend:latest

# 5. 服务器拉取并重启
ssh -i "C:\TeacherEvaluation\others\key\agent-ssh-key.pem" -o StrictHostKeyChecking=no root@124.174.17.44 "docker pull teacher-eval-cn-beijing.cr.volces.com/teacher-eval/teacher-eval-backend:latest && docker pull teacher-eval-cn-beijing.cr.volces.com/teacher-eval/teacher-eval-frontend:latest && docker-compose -f /root/docker-compose.yml down && docker-compose -f /root/docker-compose.yml up -d"

# 6. 验证
curl http://124.174.17.44/
curl -X POST http://124.174.17.44:8080/api/auth/login -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"admin123\"}"
```
