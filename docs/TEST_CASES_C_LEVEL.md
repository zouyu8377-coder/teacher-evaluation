# C级考核全业务生命周期测试用例表

> 版本：1.0
> 更新日期：2026-04-16
> 业务规则：C级活动 / 取平均分 / 及格线60分 / 每人一次考试机会 / 评分时间无限制

---

## 业务规则说明

| 规则项 | 说明 |
|--------|------|
| 活动级别 | C级（初级），无前置级别要求 |
| 考核方式 | 考试（不是材料上传） |
| 评分计算 | 多评分人取平均分，小数点后保留2位 |
| 及格标准 | 60分及以上为及格 |
| 考试次数 | 每人每个活动只有一次考试机会，未通过也不得重考 |
| 评分时间 | 无时间限制 |
| 成绩发布 | 需所有评分人完成评分后才能发布 |

| C-ERR-011 | 异常-删除关联数据 | 尝试删除有考试记录的活动 | 提示"有关联数据，无法删除" | 高 |
