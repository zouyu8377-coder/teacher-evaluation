## 二、本地部署步骤

### 2.1 启动所有服务

```bash
# 进入项目目录
cd C:\TeacherEvaluation\deploy

# 启动所有服务（首次启动会拉取镜像）
docker-compose up -d

# 查看服务状态
docker-compose ps
```

### 2.2 常用命令

```bash
# 启动服务
docker-compose up -d

# 停止服务
docker-compose down

# 查看日志
docker-compose logs -f [服务名]

# 重启单个服务
docker-compose restart [服务名]

# 进入容器
docker-compose exec [服务名] /bin/sh
```

### 2.3 访问地址

| 服务 | 地址 | 说明 |
|------|------|------|
| 前端应用 | http://localhost:80 | 用户界面 |
| 后端API | http://localhost:8080 | RESTful API |
| Swagger文档 | http://localhost:8080/swagger-ui/index.html | API文档和测试 |
| MinIO控制台 | http://localhost:9001 | 文件存储管理 |

## 三、迭代更新流程

### 3.1 重新构建镜像

**后端更新：**
```bash
# 进入后端目录
cd C:\TeacherEvaluation\backend

# 构建镜像
docker build -t teacher-eval-backend:latest .

# 重新启动
docker-compose up -d --build backend
```

**前端更新：**
```bash
# 进入前端目录
cd C:\TeacherEvaluation\frontend

# 构建镜像
docker build -t teacher-eval-frontend:latest .

# 重新启动
docker-compose up -d --build frontend
```

### 3.2 推送到远程仓库（可选）

```bash
# 标记镜像
docker tag teacher-eval-backend:latest ghcr.io/zouyu8377-coder/teacher-eval-backend:latest
docker tag teacher-eval-frontend:latest ghcr.io/zouyu8377-coder/teacher-eval-frontend:latest

# 推送镜像
docker push ghcr.io/zouyu8377-coder/teacher-eval-backend:latest
docker push ghcr.io/zouyu8377-coder/teacher-eval-frontend:latest
```
