# 教师评价考核平台 - 项目全量记录
## 一、项目概述
- **项目名称**: 教师评价考核平台
- **项目目标**: 为学校搭建教师评价系统，实现教师文档上传、考核员评分、教师查询成绩、考试管理、分级考核等核心功能
- **项目规模**: 支持200-500人使用（教师+考核员+管理员）
- **部署方式**: Windows本地测试环境 + Docker Compose 容器化

## 二、技术架构

## 三、核心功能模块
### 3.1 用户角色系统
| 角色 | 权限 | 主要功能 |
|------|------|----------|
| **教师** | 基础权限 | 文档上传、查看个人成绩、管理个人文档、报名考核、参与考试、下载学习资料 |
| **考核员** | 中级权限 | 查看教师文档、评分评语、提交考核结果、查看已报名教师 |
| **管理员** | 最高权限 | 用户管理、考核周期管理、考核活动管理、系统监控、数据统计、学习资料管理、题库管理、试卷管理、成绩发布 |

### 3.2 考核活动分级体系
- 级别顺序：C < B2/B1 < A2/A1
- C级：无前置要求，可直接报名
- B2/B1级：前置要求通过C级（B2和B1并行）
- A2/A1级：前置要求通过B2或B1（A2和A1并行）

### 3.3 核心业务流程
1. **管理员创建考核周期** → 设置考核时间范围
2. **管理员创建考核活动** → 设置级别、容量、报名时间、是否包含考试
3. **教师报名考核活动** → 系统校验报名资格（前置级别是否通过）
4. **教师参与考试（如有）** → 在线答题、自动判分
5. **教师上传考核文档** → 支持多种文件格式（最大100MB）
6. **考核员查看文档并评分** → 填写分数和评语，支持多位考核员评分取平均分
7. **管理员发布成绩** → 教师可查看考核结果和等级证书
8. **教师查看考核结果** → 查看成绩、评语、等级证书

### 3.4 考试系统功能
- 题库管理：支持单选/多选题型，难度分级
- 试卷管理：手动/随机选题，设置总分、时长
- 在线考试：断点续考、自动保存答案、自动判分
- 成绩管理：考试成绩+主观评分综合计算最终结果

## 四、数据库设计
### 4.1 核心表结构
| 表名 | 说明 |
|------|------|
| `users` | 用户表（管理员、考核员、教师） |
| `evaluation_periods` | 考核周期表 |
| `activities` | 考核活动表（分级考核） |
| `period_enrollments` | 考核活动报名表 |
| `documents` | 文档表（教师上传的考核文档） |
| `learning_materials` | 学习资料表 |
| `evaluations` | 考核评分表 |
| `exam_questions` | 考试题库表 |
| `exam_papers` | 试卷表 |
| `paper_questions` | 试卷题目关联表 |
| `exam_records` | 考试记录表 |

### 4.2 关键约束
- 评分表唯一约束：`teacher_id + activity_id`
- 报名表唯一约束：`period_id + activity_id + teacher_id`
- 软删除机制：`is_deleted`字段
- 自动时间戳记录：`created_at`/`updated_at`字段

## 五、API接口协议
### 5.1 基础信息
- 基础URL：`http://localhost:8080`
- 协议：HTTP REST
- 字符编码：UTF-8
- Content-Type：`application/json`
- 请求头需携带：`Authorization: Bearer <token>`

### 5.2 统一响应格式
```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

### 5.3 核心接口模块
| 模块 | 主要接口 |
|------|----------|
| **认证** | 登录、登出、获取当前用户 |
| **用户管理** | 用户列表、创建/更新/删除用户、教师列表 |
| **考核周期** | 周期列表、创建/更新/删除周期、当前活跃周期 |
| **考核活动** | 活动列表、可报名活动列表、报名活动、我的报名 |
| **文档管理** | 文档列表、上传、详情、更新、删除、下载 |
| **学习资料** | 资料列表、上传、下载、删除 |
| **考核评分** | 评分列表、提交评分、教师成绩查询、成绩发布 |
| **考试系统** | 题库管理、试卷管理、开始考试、提交答案、考试记录 |
| **教师首页** | 首页数据、待办事项、报名记录、成绩统计 |

### 5.4 错误码定义
| code | 说明 |
|------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或token过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
