# 教师评价考核平台 - 问题记录

> 记录日期：2026年4月15日

---

## 已发现问题

### 问题1：创建活动时类型设置错误
- **问题描述**：创建C级考核活动时，误将"考核类型"设置为"文档"而非"考试"
- **影响**：教师无法参加考试，因为文档类型活动不需要考试
- **重现步骤**：
  1. 管理员创建活动
  2. 选择级别为"C级"
  3. 考核类型默认显示为"文档"
  4. 未注意修改直接保存
- **建议**：C级活动默认考核类型应自动设置为"考试"

### 问题2：活动创建后无法修改考核类型
- **问题描述**：活动创建后，编辑活动时没有"考核类型"字段，无法更正类型
- **影响**：类型错误的活动无法修复，只能删除重建
- **建议**：在草稿状态下允许修改考核类型

### 问题3：系统中无可用的考试类型C级活动
- **问题描述**：当前系统中所有C级活动都是"文档"类型，没有"考试"类型的活动
- **影响**：无法进行完整的C级考核闭环测试（教师无法参加考试）
- **重现步骤**：
  1. 查看教师端"我的考核"页面
  2. 所有C级活动的考核类型均为"文档"
  3. 点击"开始考试"或"继续考试"按钮无反应
- **建议**：需要创建一个正确配置的"考试"类型C级活动，并关联试卷
